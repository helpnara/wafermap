## M5.5 — 도메인 보강 (다음 작업) ★

첨부해 주신 EDS 상세 정리 문서와 현재 코드를 대조해 찾은 공백입니다.
**데이터층부터 위로** 진행해야 재작업이 없습니다.

### ~~① 검사 장비 축 추가 — Prober / Probe Card / ATE~~ ✅ 완료

`wafer_master`에 `tester_id`/`probe_card_id`/`probe_touchdown`, `fdc_summary`에 검사
스텝 `T010`(검정 단위 = 프로브 카드)을 추가했다. Edge-Ring·Loc이 **공정과 검사 두
경로로** 생기며, `commonality.by_axis()`가 축별 1위를 나란히 보여준다.

성과: 검사 설비 Top-1 **100%**(2/2), 공정 설비 Top-1 **100%**(6/6) 유지.
2건 중 1건은 통합 랭킹 9위라 **축을 나누지 않았다면 놓쳤을** 원인이었다.

⚠️ 남은 문제: "검사 기인인지 **여부**"는 아직 판정 불가. 자세한 내용은
[`04_results.md`](04_results.md)의 M5.5-① 절 참조.

### ~~② 센서 시계열 파생 피처~~ ✅ 완료

`features/trace_feat.py` 6종(slope / time_above / n_excursions / peak_dev /
settle_time / range). 시뮬레이터에 스파이크형·드리프트형 이상을 심었다.

**당초 가설은 틀렸다.** "요약통계가 스파이크를 구조적으로 놓친다"는 주장은
요약값을 시계열과 따로 만들던 **내 버그** 때문에 성립하는 것처럼 보였을 뿐이다.
바로잡자 `std`가 스파이크를 잘 잡았다(AUC 0.94).

진짜 값어치는 **해석**이다. 산포를 같게 맞춘 스파이크와 드리프트를 구분하는
구분력은 0.901 → 0.969로 조금 오르지만, `time_above 2.2초 · n_excursions 1`은
"인터락을 걸어라", `slope 0.079`는 "센서를 교정해라"로 **조치가 갈린다.**
`min`이 낮다는 사실은 아무것도 말해 주지 않는다.

부수 성과로 **시드 재현성 문제**를 발견해 앞선 수치들을 정정했다
([`04_results.md`](04_results.md) 참조).

### ~~③ 공정 간 교호작용 분석~~ ✅ 완료

`analysis/interaction.py` — 2×2 분할표, 설비 조합(A→B), SHAP interaction values.
증착 `precursor_flow` × CMP `down_force` 조합을 심었다. **각각은 규격 안**이고
방향을 웨이퍼마다 뒤집어 주변부 평균이 정상군과 같다(0.12σ 차이).

성과: 설비 조합 Top-1 1위(초과 불량률 +36%p), ★필터 후 파라미터 쌍 1위.

배운 것: 대비 문턱은 불량률에 맞춰야 하고(5%p → 0.5%p), **여기서는 층화가
역효과**다 — 신호가 층 자체에 실려 있기 때문이다. M4와 정반대.

### ④ Die 단위 측정값과 Bin 부여

**왜**: 첨부 문서 §4·11.1이 "EDS는 Die 단위 **전기적 측정 데이터**를 만든다"를
핵심으로 강조하는데, 현재는 die별 pass/fail 이진값뿐입니다.
`BIN_CODES`는 `config.py`에 정의만 해 두고 아무 데서도 쓰지 않습니다.

- die별 Test Item / Measurement(연속값) 생성 → 임계로 Bin 부여
- Bin별 웨이퍼 맵(불량 유형별 색 구분) — 화면 2에서 활용
- 우선순위는 가장 낮음 (분석 결론이 바뀌지 않고 화면이 풍부해지는 수준)

## 아직 풀지 못한 한계 (정직하게 기록)

이 목록은 **숨기지 않는 것이 목적**입니다. 포트폴리오에서 수치를 인용할 때
반드시 같이 언급해야 합니다.

| 한계 | 내용 | 해소 방법 |
|---|---|---|
| **Scratch 시간 교락** | `pad_life`가 단조 카운터라 시각 대리 변수로 작동. M4 Top-1 오답의 원인 | 시간 층화 또는 카운터 파라미터 분리 취급 |
| **합성 데이터 상한** | 섭동을 직접 심었으므로 실측보다 신호가 깨끗하다 | M7 실데이터 재측정 |
| **검정력 부족** | 6,000장(240 lot)에서 유의 판정 0~1개. 순위는 맞지만 확증은 못 한다 | 표본 확대 또는 실데이터 |
| **SPC 위양성 판정** | 전체 121일 중 89일(74%)이 이상 구간이라 판정 여지가 좁다 | 정상 기간 비중을 늘린 시나리오 |
| **상관 ≠ 인과** | 모든 개선안이 상관 기반. DOE 대상 축소용으로만 유효 | 구조적 한계 — 명시가 최선 |
| **검사 기인 여부 판정 불가** | 어느 카드인지는 찾지만(2/2), 검사 기인이 **있는지 없는지**는 못 가린다. 검사 축 OR이 원인 없을 때 오히려 크다(4.00 vs 2.14) | 재검사 데이터 필요 — 구조적 한계에 가깝다 |
| **카운터의 시각 교락 (확대)** | `pad_life`(M4)에 이어 `touchdown_count`도 같은 함정. 단조 증가 카운터가 시각 대리 변수로 작동 | 시간 층화 또는 카운터 파라미터 분리 취급 |
| **시드 의존성** | 채점이 시드 하나에 크게 흔들린다(M3 챔버 Top-1 67% ± 17%). 단일 실행 수치는 인용 불가 | 시드 반복 측정을 기본으로 (`run_seed_study.py`) |
| **스파이크 검출은 해상도 가정에 의존** | 60초를 60점으로 본다. 실측 FDC가 더 성기면 `time_above`가 무의미 | 실측 로그 주기 확인 후 재설계 |
| **교호작용 미분석** | 단일 파라미터 주효과만 본다 | **M5.5-③** |
