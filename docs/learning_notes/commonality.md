# 커미널리티 분석 — "어느 설비가 범인인가"

## 이 코드는 무엇을 하나

**입력**: 이상군 웨이퍼 목록 + 정상군 웨이퍼 목록 + FDC 이력
**출력**: 챔버별 랭킹

```
ETCH-B/ch2 — 이상군 7/24(29.2%) vs 정상군 13/215(6.0%) · OR 6.4 · p_adj=5.1e-02
```

발상은 **역학 조사와 똑같다.** 식중독 환자 50명이 생겼을 때 "이 사람들이 공통으로
먹은 음식이 뭐지?"를 찾는 것과 같다. 웨이퍼도 이력을 모아 놓고 공통점을 찾는다.

## 왜 이 단계가 중요한가

**수백 개 공정, 수십 대 장비 중 어디를 봐야 할지 좁혀 준다.**
이 단계 없이 FDC 파라미터 수백 개를 바로 뒤지면 시간이 너무 걸린다.

그리고 **조치 단위가 챔버이기 때문**이기도 하다. "식각 장비가 문제"로는 아무것도
못 한다 — 장비를 세우면 생산이 멈춘다. "4개 챔버 중 3번만 문제"면 그 챔버만
잠그면 되므로 생산 손실이 4분의 1이 된다.

## 핵심 로직

### 기본 골격: 2×2 표와 Fisher 검정

챔버마다 이런 표를 만든다.

```
              이 챔버 통과   안 지남
  이상군           7           17
  정상군          13          202
```

그리고 "이 차이가 우연일 확률"을 계산한다.

```python
        _, p_value = fisher_exact([[a, b], [c, d]], alternative="greater")
```

**왜 카이제곱이 아니라 Fisher인가?** 카이제곱은 기대빈도가 5 미만인 셀에서
근사가 깨진다. 챔버가 37개면 표본이 잘게 쪼개져 저빈도 셀이 흔해진다.
Fisher는 정확검정이라 표본이 적어도 올바른 p-value를 준다.

### 함정 ①: 다중검정 — 챔버 37개를 동시에 검정하면

유의수준 5%는 "정상인데 이상하다고 잘못 볼 확률이 5%"라는 뜻이다.
**37개를 동시에 검정하면 아무 문제가 없어도 약 2개가 걸린다.**

```python
    reject, p_adj, _, _ = multipletests(result["p_value"], alpha=alpha, method="fdr_bh")
```

이 한 줄이 없으면 우연히 유의해 보이는 것들이 그대로 보고된다.
그리고 **보정된 `p_adj`를 봐야 하고, 원래 `p_value`를 보면 안 된다.**

### 함정 ②: 표본 단위 — 이 프로젝트에서 가장 큰 발견 ★★

처음에는 웨이퍼 단위로 검정했다. 결과가 이랬다.

```
Loc      OR = 582.0   p_adj = 8.6e-63
Edge-Loc OR = 400.8   p_adj = 4.7e-56
```

오즈비 582에 p값 10⁻⁶³. **너무 좋아서 이상하다.**

원인은 **표본을 25배로 부풀린 것**이었다.

```
팹은 lot(25장) 단위로 설비를 배정한다.
  → 같은 lot의 25장은 독립 관측이 아니다
  → 한 lot이 어느 챔버를 썼는지는 25번이 아니라 한 번 결정된 사건
```

웨이퍼 단위로 세면 실제 정보량의 25배를 가진 것처럼 계산된다.
그러면 **사소한 차이도 압도적으로 유의**해져, 진짜 원인과 우연한 상관을 구분할 수 없다.

lot 단위로 고친 뒤:

| | 웨이퍼 단위 | lot 단위 |
|---|---|---|
| 표본 (Edge-Ring) | 336 / 5,115 | 24 / 215 |
| Top-1 OR 범위 | 5.2 ~ **582.0** | 4.2 ~ 28.0 |
| 유의 판정 평균 | 9.2개 | 0.3개 |
| **Top-1 챔버 적중률** | **83%** | **100%** |

**표본 단위 하나를 고친 것만으로 적중률이 83% → 100%가 됐다.**

특히 Center 패턴이 극적이다. 웨이퍼 단위에서는 무관한 `ETCH-B/ch4`(OR 5.2)가
진범 `CMP-01/ch2`(OR 4.1)를 눌렀다. 표본 부풀림이 우연한 상관을 증폭시킨 것이다.
lot 단위로 바꾸자 진범이 1위로 올라왔다.

```python
        df = (
            df.groupby(["step_id", "chamber_id", "equip_id", "_unit"], as_index=False)
            .agg(_is_case=("_is_case", "any"))
        )
```

`any`를 쓰는 이유: 이상군 웨이퍼가 **한 장이라도** 있으면 그 lot은 문제의 설비를
거쳤을 가능성이 있다. 반면 정상군은 순수해야 대조가 성립한다.

### 함정 ③: 교락 — 진범과 늘 붙어 다닌 무고한 설비

공장의 lot 배정에 규칙성이 있으면 특정 장비 조합이 함께 흐른다.

```
진범:  ETCH-B/ch3  → 불량률 22%   ← 진짜 원인
무고:  CMP-01/ch2  → 불량률 19%   ← 같이 흘렀을 뿐
```

단순 교차표로는 둘 다 유의하게 나온다. **CMH 층화 검정**이 이를 가른다.

```python
    st = StratifiedTable(np.dstack(tables))
    adjusted_or = float(st.oddsratio_pooled)
```

CMP 챔버별로 층을 나눈 뒤, **각 층 안에서만** 식각 챔버의 효과를 본다.
효과가 남으면 식각이 진범이고, 사라지면 CMP와의 동행 때문이었던 것이다.

> 💡 아이스크림 판매량과 익사 사고는 함께 늘어난다. 하지만 원인은 **더운 날씨**다.
> "더운 날끼리만" 비교하면 관계가 사라지는데, 그게 층화다.

## 결과 — 정답지 대비 채점

```
  Center      정답 P050  Top1챔버 ✅  Top1스텝 ✅  1위=CMP-01/ch1 (OR 4.2)
  Donut       정답 P030  Top1챔버 ✅  Top1스텝 ✅  1위=CVD-01/ch2 (OR 16.7)
  Edge-Loc    정답 P060  Top1챔버 ✅  Top1스텝 ✅  1위=CLN-01/ch1 (OR 21.7)
  Edge-Ring   정답 P020  Top1챔버 ✅  Top1스텝 ✅  1위=ETCH-B/ch2 (OR 6.4)
  Loc         정답 P010  Top1챔버 ✅  Top1스텝 ✅  1위=SCAN-03/ch1 (OR 28.0)
  Scratch     정답 P050  Top1챔버 ✅  Top1스텝 ✅  1위=CMP-02/ch2 (OR 15.8)

  원인 스텝 Top-1 적중률 : 100% (6/6)
  원인 챔버 Top-1 적중률 : 100% (6/6)
```

**6개 패턴 모두 진범을 1위로 지목했다.**

### 그런데 유의 판정은 0~1개뿐이다 — 이것을 어떻게 읽을 것인가 ★

```
Edge-Ring  1위 OR 6.4,  p_adj = 5.1e-02   ← 아슬아슬하게 유의하지 않음
Center     1위 OR 4.2,  p_adj = 1.0e+00   ← 전혀 유의하지 않음
```

순위는 100% 맞는데 통계적으로는 유의하지 않다. 모순처럼 보이지만 아니다.

**이상군이 11~24 lot뿐이라 검정력이 부족한 것이다.** 표본 크기를 늘려 확인했다.

| 웨이퍼 | lot | Edge-Ring p_adj | Center p_adj | Top-1 적중 |
|---:|---:|---|---|---|
| 6,000 | 240 | 5.9e-03 | 6.3e-02 | ✅ |
| 24,000 | 960 | 3.1e-25 | 1.8e-02 | ✅ |
| 60,000 | 2,400 | 2.0e-04 | 1.7e-03 | ✅ |

**표본이 늘어나면 유의성이 확보된다. 순위는 처음부터 맞았다.**

> ⚠️ **"유의하지 않다"가 "원인이 아니다"를 뜻하지 않는다.**
> 표본이 부족할 뿐일 수 있다. 실무에서 이 구분을 못 하면
> 진짜 원인을 "통계적으로 유의하지 않으니 무시"하고 넘어가게 된다.

## 왜 이렇게 만들었나 — 설계 선택과 대안

### 선택 1: 왜 `alternative="greater"` 단측 검정인가?

우리가 묻는 것은 "이 챔버가 불량을 **늘렸는가**"이지 "달라졌는가"가 아니다.
불량률을 낮추는 챔버는 범인 후보가 아니므로 한쪽 방향만 본다.
단측 검정은 같은 데이터에서 검정력이 더 높다.

### 선택 2: 왜 오즈비에 0.5를 더하나 (Haldane 보정)?

```python
    a_, b_, c_, d_ = a + 0.5, b + 0.5, c + 0.5, d + 0.5
```

셀에 0이 하나라도 있으면 오즈비가 0이나 무한대가 된다. 표본이 적은 반도체 분석에서는
"이상군 중 이 챔버를 지난 웨이퍼 0장" 같은 상황이 흔하다. 0.5를 더하면 유한한 값이
나오고, 표본이 크면 영향이 무시할 만큼 작아진다.

### 선택 3: 왜 상위 후보만 층화 검정하나?

```python
    significant = ranking[ranking["significant"]].head(top_n)
```

모든 조합을 검정하면 **그것 자체가 또 다른 다중검정 문제**를 만든다.
37개 챔버 × 36개 층화 조합 = 1,332번 검정이다.
유의하게 나온 소수 후보에만 적용하는 것이 표준 절차다.

### 선택 4: 왜 `unit="wafer"` 옵션을 남겨 뒀나?

측정된 결과가 나쁜데도 지웠으면 **"왜 lot이어야 하는가"를 보여줄 수 없다.**
학습 목적으로 두 방식을 나란히 돌려 볼 수 있게 남겼다.

```bash
python scripts/run_commonality.py --compare-units
```

## 확인 문제

**1.** 오즈비 582에 p_adj=8.6e-63이 나왔다. 왜 의심해야 하는가?

<details><summary>정답</summary>

**너무 좋기 때문이다.** 실제 공정에서 특정 챔버가 불량 가능성을 582배 높이는
일은 거의 없다. 그런 장비라면 진작 발견됐을 것이다.

원인은 표본 부풀림이었다. 웨이퍼 단위로 세면 같은 lot의 25장이 독립 관측으로
취급되어, 실제 정보량의 25배를 가진 것처럼 계산된다.

> 성능이나 통계량이 예상보다 훨씬 좋게 나오면, 기뻐하기 전에 방법을 의심하는 것이 좋다.
</details>

**2.** lot 단위로 바꿨더니 Center 패턴의 1위가 `ETCH-B/ch4`에서 `CMP-01/ch1`로
바뀌었다. 무슨 일이 일어난 것인가?

<details><summary>정답</summary>

`ETCH-B/ch4`와 Center의 상관은 **우연**이었다. 그런데 웨이퍼 단위 검정이
표본을 25배 부풀리면서 그 우연한 상관까지 증폭시켰고, 결과적으로 진짜 원인인
CMP를 눌러 버렸다.

lot 단위로 표본을 올바르게 세자 우연한 상관은 힘을 잃고 진범이 1위로 올라왔다.

**표본 단위를 잘못 잡으면 순위 자체가 뒤집힌다**는 것을 보여 주는 사례다.
</details>

**3.** 1위가 정답인데 `p_adj = 1.0`이다. 이 결과를 어떻게 보고해야 하는가?

<details><summary>정답</summary>

**"CMP-01/ch1이 가장 유력한 후보이나, 현재 표본(11 lot)으로는 통계적으로
확증할 수 없다. 데이터를 더 모으거나 해당 챔버의 FDC 파라미터를 직접 확인할 것을 권한다."**

"유의하지 않으니 원인이 아니다"라고 결론 내리면 안 된다. 검정력 부족과
효과 없음은 다른 이야기다.

실무에서는 이럴 때 통계적 유의성 대신 **물리적 타당성**(그 공정이 이 패턴을
만들 수 있는가)과 **FDC 파라미터 확인**으로 보완한다.
</details>

**4.** 층화 검정에서 조정 오즈비가 원래의 절반 미만으로 떨어지고 유의성도
사라졌다. 무엇을 뜻하는가?

<details><summary>정답</summary>

**교락이었을 가능성이 높다.** 그 설비 자체가 원인이 아니라, 층화에 쓴 다른 설비와
함께 흘렀기 때문에 상관이 보였던 것이다.

층화한 설비를 고정하자 효과가 사라졌다는 것은, 원래 상관이 그 설비를 경유한
간접 효과였다는 뜻이다.

실무적으로는 그 설비를 후보에서 내리고 층화에 쓴 설비를 더 자세히 봐야 한다.
</details>

## 더 알아보기

- **Fisher 정확검정**: 초기하분포로 정확한 p-value를 계산. 표본이 크면 계산이 무거워
  카이제곱을 쓰지만, 반도체 분석은 대개 표본이 작아 Fisher가 적합하다
- **Benjamini-Hochberg FDR**: Bonferroni보다 덜 엄격해 탐색적 분석에 적합.
  "몇 개는 헛다리를 짚더라도 진짜 원인은 놓치지 말자"는 상황에 맞는다
- **Cochran–Mantel–Haenszel**: 층화된 2×2 표를 종합하는 표준 방법. 역학에서 유래
- **군집 표본(clustered sampling)**: lot처럼 묶여 있는 데이터의 유효 표본 수를 다루는 통계 분야.
  더 정교하게는 GEE나 혼합효과모형을 쓴다
- 관련 모듈: [`spc.md`](spc.md) — 이상군/정상군을 나눠 이 분석에 넘긴다
